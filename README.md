# 审核小助手

一个用于 `admin.fantacy.live` 审查后台的 Chrome 扩展(内部工具):在列表页悬停某行按 **A 通过 / D 拒绝**,详情页同样支持 A/D 决策,加快审查速度。

## 快速安装

Chrome 不支持从 GitHub 直接一键安装扩展,需要「开发者模式 + 加载文件夹」,一次性设置约 1 分钟:

1. **下载代码**
   - 简单方式:点仓库页右上 **Code → Download ZIP**,解压。
   - 或者:`git clone <本仓库地址>`(以后 `git pull` 就能更新)。
2. 打开 Chrome,地址栏进 `chrome://extensions`。
3. 打开右上角 **开发者模式**。
4. 点 **加载已解压的扩展程序**,选择解压出的 `fantacy-review-helper` 文件夹。
5. 打开审查页面,左下角出现状态条即成功。

详细图文见 [安装说明.md](安装说明.md)。

## 用法速查

| 场景 | 操作 |
|------|------|
| 列表页 | 鼠标悬停某行(出现绿框)→ 按 `A` 通过 / `D` 拒绝 |
| 详情页 | 按 `A` 通过 / `D` 拒绝 |
| 临时停用 | 左下角面板「暂停」，或 `chrome://extensions` 关开关 |

在输入框内打字时 A/D 不会触发。

## 更新

- `git clone` 安装的:`git pull` 后到 `chrome://extensions` 点该扩展的刷新图标。
- ZIP 安装的:下载新版覆盖文件夹,重新加载。
- 以左下角版本号(如 `v2.0`)为准。

## 文件说明

- `manifest.json` — 扩展配置(Manifest V3)
- `content.js` — 全部逻辑(注入到 admin.fantacy.live 页面)
- `安装说明.md` — 给同事看的中文安装与使用说明
